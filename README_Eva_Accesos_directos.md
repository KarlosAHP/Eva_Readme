## 🏗️ Arquitectura y Principios del Sistema

* **Zero-Knowledge & Cero Bases de Datos Externas:** La operativa descansa exclusivamente en contenedores locales cifrados (`.json`) mediante AES-GCM y PBKDF2. Ningún dato confidencial transita por servidores de terceros.
* **Estanqueidad Absoluta:** Aislamiento total de perfiles y credenciales para garantizar que la información del operador permanezca incomunicada y blindada ante cualquier auditoría externa o intento de extracción.
* **Soberanía del Operador:** La custodia de las llaves recae de forma exclusiva en el usuario. Sin claves de acceso, la recuperación de datos es criptográficamente imposible por diseño.

## 🛠️ Herramientas, stack y conocimientos aplicados

Este módulo está construido con herramientas de producción real, seleccionadas para máxima seguridad, cumplimiento y soberanía de datos:

* **Lenguaje y runtime:** HTML5, CSS3, JavaScript ES6+, Chrome Extensions API (Manifest V3).
* **Cifrado y autenticación:** AES-GCM, PBKDF2, hashing criptográfico, Zero-Knowledge.
* **Persistencia:** Chrome Storage Local, JSON cifrado portable, sin bases de datos externas para credenciales.
* **Infraestructura:** Empaquetado como extensión de navegador, ofuscación de producción.
* **Gobernanza:** Git, GitHub, control de versiones, documentación técnica.

### 🧠 Destrezas y conocimientos que hacen posible este módulo

* Desarrollo de extensiones de navegador seguras con Manifest V3 y aislamiento de privilegios.
* Criptografía aplicada: cifrado simétrico, derivación de claves y protección de datos en reposo.
* Diseño de sistemas Zero-Knowledge sin exposición de secretos.
* Arquitectura de interfaces browser-side con módulos independientes (accesos, notas, ideas, agenda).
* Implementación de estanqueidad y soberanía del operador en entornos cliente.
* Documentación técnica orientada a usuarios finales, clientes y auditores.
